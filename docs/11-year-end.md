# 年度末の手順

個人事業主（青色申告）の1年を締めて、確定申告に使う資料を出すまでの順序。

**順序に意味がある。** 特に「決算書を出す」と「決算振替を記帳する」は
入れ替えると決算書が壊れる（§4）。

---

## 1. 期中の記帳を年末まで済ませる

12月31日までの取引をすべて記帳する。

```sh
kaikei verify --year 2026
```

不整合が無いことを確認する。**「検査が走った」ことと「異常が無かった」ことは
別**なので、終了コードも見ること（不整合があれば 1 になる）。

---

## 2. 決算整理仕訳を入れる

帳簿に自動では出てこないものを、この段階で仕訳として入れる。
**額はいずれも税務判断を含む。このソフトは計算しない。**

| 項目 | 備考 |
|---|---|
| 減価償却費 | 個人事業主は**強制**（所得税法49条。償却しないという選択はできない） |
| 家事按分の年次調整 | 期中に按分していない分 |
| 棚卸 | 商品を持つ業種のみ |
| 貸倒引当金 | 繰入・繰戻 |

### 減価償却費

このソフトは**固定資産台帳を持たない**（`ROADMAP.md` の「Phase 5 以降の
検討事項」）。取得価額・取得日・耐用年数・償却方法から償却額を出すのは
利用者（または税理士）の仕事で、結果を仕訳として記帳する。

```
借方  610 減価償却費    xxx,xxx
貸方  205 機械装置        xx,xxx
      210 工具器具備品    xx,xxx
      220 車両運搬具      xx,xxx
```

`610 減価償却費` は決算書の⑱に当てはめてあるので、記帳すればそのまま
決算書に載る（`blue_return_general.yaml`）。

取得価額によっては、資産計上せず経費にできる制度がある（少額減価償却資産の
特例、一括償却資産など）。**どれを使うかは税務判断**なので、このソフトは
判定しない。

---

## 3. 決算書と帳簿を出す

**まだ決算振替は記帳しない。**

```sh
kaikei report --year 2026 --out ./out-2026
kaikei report --year 2026 --out ./out-2026 --yayoi   # 税理士に渡す場合
```

出るもの:

| ファイル | 中身 |
|---|---|
| `journal_book` / `general_ledger` / `trial_balance` | 帳簿 |
| `balance_sheet` / `income_statement` | 財務諸表 |
| `blue_return` | 青色申告決算書（損益計算書）①〜㊺ |
| `blue_return_balance_sheet` | 同（貸借対照表）期首・期末 |
| `blue_return_not_on_form.csv` | 決算書に載らなかった科目 |
| `export.json` | 帳簿の全件（このソフトが無くても読める形） |
| `yayoi_journal.csv` | 弥生インポート形式（`--yayoi` 指定時） |

### 出力時の注意を読む

画面に出る「注意」は**読み飛ばさないこと**。次はいずれも決算書が誤ったまま
提出されうる状態を指している。

- 貸借対照表の資産合計と負債・資本合計がずれている
- 決算書のどの欄にも載らない科目がある
- 青色申告特別控除額（既定 65 万円）の要件を満たすか **このソフトは判定しない**

---

## 4. 決算書を確かめてから決算振替を記帳する

**この順序を守る。**

決算振替を記帳すると、損益が元入金へ振り替わって**期末の元入金が動く**。
一方、決算書の貸借対照表は「元入金は期首と期末が同額」を前提にしている
（当期の所得は「青色申告特別控除前の所得金額」の行に別途書くため）。

つまり**振替を先に記帳すると、決算書の元入金と所得金額の両方が狂う**。

```sh
# 提案を見る（記帳はされない）
propose_closing_entries { "fiscal_year": 2026 }
# → 内容を確認してから post_journal_entry に渡す
```

振替後に決算書を出そうとすると、CLI が次を知らせる。

```
注意: 決算書は「元入金」が期首と期末で同額であることを前提にしていますが、
      帳簿では期首 X / 期末 Y と動いています。
```

これが出たら、**決算書は振替前の帳簿から作り直す**。

---

## 5. 出力一式を保存する

帳簿書類の保存期間は7年（欠損金の繰越があれば10年）。

- `export.json` を**別の場所にも**残す。PostgreSQL のバージョンにも、この
  プロジェクトの存続にも依存しない形で読める（`docs/03-database.md` §8）
- `pg_dump` も併せて取る
- 印刷用 HTML は見読可能性の要件に対応する（`docs/08-compliance.md`）

---

## 6. 税理士に確認すること

`docs/09-tax-research.md` に一次情報での裏取り結果があるが、**一次情報調査は
税理士レビューを代替しない**。少なくとも次は確認の対象。

- 減価償却の方法と、少額減価償却資産の特例を使うかどうか
- 弥生向けの税区分の写像（`kaikei-jp-data/yayoi/tax_categories.yaml` は
  各行が `verified: false`。実機で取り込めることを確かめていない）
- 青色申告特別控除額の要件を満たすか
- 事業所得に含めない収益の扱い（受取利息など。除いた分の相手科目を
  事業主借へ振り替えないと貸借対照表が合わない）
